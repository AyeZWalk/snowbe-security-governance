# Illustrative control review for a fictional retailer

This portfolio adaptation shows what evidence a reviewer could request to determine whether a proposed policy is working.

| Control area | Example owner | Evidence to review |
| --- | --- | --- |
| Access reviews | System owner | Current role assignments, approval record, and dated follow-up for revoked access |
| Incident readiness | Security lead | Escalation list, tabletop exercise record, and a follow-up owner for each finding |
| Patch management | Infrastructure lead | Patch inventory, validation record, exception expiration, and rollback plan |
| Recovery | Service owner | Dated restore record, measured recovery time, and evidence that key data can be retrieved |
| Secure changes | Engineering lead | Design review, updated threat model, release checklist, and decision on outstanding risk |

Reassess each control when implementation evidence is available. Use the review to assign owners, prioritize remediation, and verify the next round of changes.
